# Paquete de evidencias SOIN GROW 2026

## Archivos

- `SOIN_GROW_2026_Evidencias.xlsx`: tablero, evidencias localizadas, inventario de 20 pruebas y plan de transferencia.
- `Informe_GROW_2026.html`: informe visual en primera persona, con enlaces a commits y resumen de los ocho objetivos. Abrir en navegador o imprimir como PDF.
- `Informe_GROW_2026.pdf`: versión lista para compartir e imprimir del informe visual.
- `01_AI_3x_plantilla.md`: tres fichas para demostrar productividad AI-First, precargadas con FrontRoulette, ResponsiveRoulette y Television Raffle de TappWeb.
- `01_candidatos_AI_3x_TappWeb.md`: tres entregables TappWeb con alcance Git verificable para evaluar como los dos casos 3x faltantes.
- `06_optimizacion_flujos_SIGES.md`: fichas de Home, Companies y Contracts; indica exactamente las capturas o registros de Network necesarios para cerrar objetivo 6.
- `08_transferencia_practicas_AI_First.md`: material y registro para completar el objetivo 8.

## Cómo usarlo

1. Subiré estos archivos a la carpeta SOIN GROW en Drive.
2. Abriré el Excel y reemplazaré los estados `Candidato` por `Cumplido` solo cuando exista la evidencia indicada en la columna `Falta para cierre`.
3. Adjuntaré la captura original del Indicador Semanal como `02_indicador_semanal.png`. Respalda 96% de mi tiempo productivo, con histórico enero-agosto entre 91% y 100%.
4. Para objetivo 1, confirmaré las duraciones de TappWeb y sumaré dos casos comparables con productividad >=3x. FrontRoulette estima >=5x; Television Raffle 2x; ResponsiveRoulette 1.67x. Revisaré `01_candidatos_AI_3x_TappWeb.md` para tres candidatos adicionales. Los tiempos excluyen cambios posteriores.
5. Confirmaré con mi jefatura el backlog prioritario del objetivo 3 y el período exacto de evaluación.
6. Para el objetivo 6, completaré `06_optimizacion_flujos_SIGES.md` con captura, Network o métrica verificable del antes y después de Home, Companies y Contracts, además de cómo usé IA.
7. Ejecutaré dos sesiones del objetivo 8 y guardaré por cada participante la minuta, tres prácticas aplicadas y enlaces a PRs.

## Límite importante

Los PRs, commits y archivos localizados prueban que existen cambios y pruebas. No prueban por sí solos la aceptación del backlog, el 3x, la ejecución de pruebas, métricas de rendimiento o que otros desarrolladores aplicaron prácticas. El paquete deja cada condición pendiente visible para cerrarla con evidencia real.
